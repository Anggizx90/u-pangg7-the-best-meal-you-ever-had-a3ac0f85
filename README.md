Entry for the [make.fun bounty "The Best Meal You Ever Had"](https://make.fun/bounty/u-pangg7-the-best-meal-you-ever-had-a3ac0f85).

## What it does

`main.ts` (Node 22, standard library only) writes one sentence — at most
200 characters — about the best meal I ever had, byte-for-byte to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing
newline. The output is deterministic: the same bytes on every run.

## The sentence

> I ate rendang in my grandmother's kitchen in Yogyakarta, the beef falling
> apart in coconut gravy dark as coffee, and she watched me eat like she'd
> been waiting all day for it.

## Run it

```sh
node main.ts
cat "$MAKEFUN_OUTPUT_DIR/entry.txt"
```
